✅ Por que OFX é melhor?
O OFX é um arquivo de dados estruturados — como uma planilha. Cada transação tem data, valor e descrição exatos, sem erros de interpretação. É o formato mais preciso.
Como exportar o OFX no seu banco:
🟣 NubankPerfil → Meu extrato → Exportar → OFX
🔵 ItaúExtrato → Exportar dados → Formato OFX
🔴 BradescoExtrato → Salvar extrato → OFX / Money
🟠 SantanderInternet Banking → Extrato → Exportar OFX
🟢 InterExtrato → Exportar → OFX
⚫ C6 BankExtrato → Baixar → OFX
🔵 BBBanco do Brasil → Extrato → Exportar OFX
📄 Extrato em PDF
O app lê o texto do PDF e identifica as transações automaticamente. Funciona melhor com PDFs gerados pelo app do banco (não escaneados).
⚡
Toque para selecionar o arquivo OFX
Arquivo .ofx ou .qfx exportado pelo seu banco
🔒 Lido no seu celular — nada é enviado para servidores
